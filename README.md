# ASTRO-AutoFix — СТО Львів

Сучасний вебсайт автосервісу у Львові на Astro з підтримкою Cloudflare Workers.

## Запуск

```sh
npm install
npm run dev
```

## Збірка

```sh
npm run build
npm run preview
```

Статичний результат — `dist/`.

## Сторінки та функції

Головна, послуги з фільтрацією, 8 сторінок послуг, ціни з категоріями, про нас, галерея з фільтрами та переглядом фото, відгуки, контакти, конфіденційність та 404.

Адаптивна навігація, доступні діалоги, форма запису з перевіркою полів і локальним збереженням. Запити не надсилаються на сервер. Перед запуском підключіть обробник заявок, замініть демонстраційні контакти, графік, ціни та відгуки.
